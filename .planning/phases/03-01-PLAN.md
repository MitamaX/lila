# Phase 3: Lichess Logic Integration

## Goal
Integrate Lichess's core analysis logic for move judgements (Inaccuracy, Mistake, Blunder, Brilliant, Great Move) and overall accuracy calculation.

## Tasks
- [ ] 3-1: Update `Advice.scala` to support "Brilliant" and "Great Move" grades.
- [ ] 3-2: Implement "Brilliant" and "Great Move" detection logic in `Advice.apply`.
- [ ] 3-3: Verify accuracy calculation in `AccuracyPercent.scala` against Lichess standards.
- [ ] 3-4: Create unit tests to verify move judgements.
- [ ] 3-5: Verify `Annotator` correctly applies the new grades to PGN output.

## Technical Details

### 3-1: Update `Advice.scala`
- Add `Brilliant` and `GreatMove` to `Advice.Judgement` enum.
- Update `Judgement.glyph` mapping.
- Update `Advice.makeComment` to handle new judgements.

### 3-2: Detection Logic
- **Brilliant Move**:
  - Delta winning chance < 0.05 (no significant drop).
  - Best move (or at least one of top moves).
  - Sacrifice involved (material change check).
- **Great Move**:
  - Delta winning chance < 0.05.
  - The move is significantly better than other options (recovery or holding advantage).

### 3-4: Testing

- Test cases for:
  - Standard Inaccuracy/Mistake/Blunder.
  - A known "Brilliant" sacrifice.
  - A "Great Move" recovery.
