# Phase 4: API & Reporting

## Goal
Implement a stateless REST API for PGN analysis and advanced reporting, including accuracy, move judgements, ECO information, and game statistics.

## Tasks
- [x] 4-1: Implement `AnalyzeApi` controller and add the `POST /api/analyze` route.
- [x] 4-2: Create `AnalysisService` in `modules/analysis-api` to coordinate PGN parsing, engine analysis, and Lichess logic.
- [x] 4-3: Implement `ReportGenerator` for JSON and annotated PGN output (Glyphs, Variations).
- [x] 4-4: Integrate `lila.opening.EcoRes` for opening identification (ECO) and calculate game phase statistics.
- [x] 4-5: Add unit tests for `AnalysisService` and integration tests for the API endpoint.

## Technical Details

### 4-1: API Controller & Routing
- **File**: `app/controllers/AnalyzeApi.scala`
- **Action**: Create a controller that accepts a POST request with a PGN string.
- **Route**: `POST  /api/analyze  controllers.AnalyzeApi.analyze` in `conf/routes`.
- **Handling**: Parse PGN, call `AnalysisService`, and return the generated report.

### 4-2: Analysis Service
- **File**: `modules/analysis-api/src/main/scala/lila/analysisApi/AnalysisService.scala`
- **Action**: 
  - Parse PGN moves using `lila.common.pgn.PgnParser`.
  - Use `AnalysisOrchestrator.analyze` to get raw `List[Info]`.
  - Convert `List[Info]` to `lila.tree.Analysis`.
  - Calculate `Advice` and `AccuracyPercent` for both players.

### 4-3: Report Generation
- **File**: `modules/analysis-api/src/main/scala/lila/analysisApi/ReportGenerator.scala`
- **JSON**: Include `accuracy`, `summary` (judgement counts), and `evals` per ply.
- **PGN**: Use `lila.tree.Annotator` to generate a PGN string with glyphs (!!, !, ?!, ?, ??).

### 4-4: ECO & Statistics
- **ECO**: Use `lila.opening.EcoRes` to identify the opening name and ECO code from the PGN.
- **Stats**: Calculate move counts for Opening, Middlegame, and Endgame phases (using `lila.tree.Division`).

### 4-5: Testing
- **Unit**: Verify `AnalysisService` correctly assembles the `Analysis` object and calculates accuracy.
- **Integration**: Verify `POST /api/analyze` returns the expected JSON structure for a valid PGN.
